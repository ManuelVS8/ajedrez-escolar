# ajedrez-escolar
Archivos para crear plataforma escolar de ajedrez.

Qué incluye
    • App del alumnado: lecciones desde cero, ejercicios de táctica, «Mi camino» con diploma final, partidas contra la máquina y online, torneos, clasificación, estudios y análisis de partidas. 
    • App del profesorado: alta del alumnado con usuario y clave, PDF de claves para imprimir, torneos (arena, suizo y todos contra todos), salón de la fama, tareas y fichas, y grupo Club con su profesorado. 
Cómo funciona
    • Cada centro tiene su propia copia, en sus propias cuentas gratuitas de Firebase (Google) y GitHub. Ningún dato del alumnado pasa por otro centro. 
    • Incluye un configurador: escribes el nombre del centro, subes el logo y se generan todos los archivos. 
    • Trae una guía ilustrada paso a paso. Se monta en alrededor de una hora y no hace falta saber programar.
